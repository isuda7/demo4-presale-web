# 시작 전 선택사항 체크리스트

처음 시작할 때(진행 기록이 없을 때) **한 번만**, 아래 리스트를 한 메시지로 보여 주고 한 번의 답을 받는다.
항목을 하나씩 따로 묻지 않는다. 답을 받으면 바로 기본 환경부터 진행한다.

## 보여 주는 형식
요청에 이미 들어 있는 내용(예: "팝업은 슬라이드로")은 미리 반영해서 체크해 둔다.
카탈로그를 이미 받았으면 1번에 파일명을 적어 둔다.

```
시작 전에 전체 단계의 선택사항입니다. [✔]가 기본값입니다.
모두 기본값이면 "진행"이라고만 답해 주세요. 바꿀 것만 "5번 사용 안 함, 10번 슬라이드"처럼 적어 주시면 됩니다.

■ 필수
 1. 카탈로그 파일 : ○○○.pdf (확인됨)      ← 없으면 "파일을 첨부해 주세요"

■ 진행 방식
 2. 단계 진행      : [✔] 단계마다 멈추고 결과 확인  [ ] 멈추지 않고 끝까지 연속 진행
 3. 디자인 확인    : [✔] 디자인 시스템 시안 후 한 번 멈춤  [ ] 멈추지 않고 페이지까지 진행

■ 홍보 사이트
 4. 메뉴 구성      : [✔] 카탈로그 장 구성대로 자동  [ ] 직접 지정(메뉴명 적어 주세요)
 5. 스크롤 등장 효과(AOS) : [✔] 사이트 전체 적용  [ ] 사용 안 함
 6. 헤더 배경 블러 : [✔] 적용  [ ] 미적용

■ 분양 접수
 7. 신청 항목      : [✔] 이름·휴대폰·관심타입·방문희망일·문의·개인정보 동의(필수)·마케팅 동의(선택)
                     [ ] 추가·제외(항목 적어 주세요)
 8. 관리 상태값    : [✔] 신규·연락완료·방문예약·계약·보류  [ ] 직접 지정
 9. 중복 신청 제한 : [✔] 같은 번호 24시간  [ ] 제한 없음  [ ] 기간 지정

■ 사이트 콘텐츠 운영
10. 팝업 노출 방식(초기값) : [✔] 개별 팝업  [ ] 슬라이드 팝업   (관리자에서 언제든 변경 가능)
11. 기본 팝업     : [✔] 이벤트 + 긴급공지 2개  [ ] 직접 지정  [ ] 넣지 않음

(고정 사항: 메뉴별 페이지, 헤더 내비게이션 하나, 디자인 시스템 공통 적용, 관리자 비밀값 환경변수 처리,
 인라인 편집 관리자 전용, 팝업이 열릴 때 포커스 안 보이게 시작 — 이미 정해진 사항이라 묻지 않습니다.)
```

## 답을 받은 뒤
- 답을 해석해 확정값을 정한다. 애매한 항목만 한 번에 모아 짧게 되묻고, 나머지는 기본값으로 둔다.
- 확정값을 기록한다.
  - 로컬 프로젝트: 1단계에서 `doc/project-options.md`에 표로 남긴다. 이후 단계는 이 파일을 읽어 따른다.
  - 프로젝트 파일이 없는 환경: 확정값을 대화에 한 번 정리해 두고, 이후 단계는 그 정리를 따른다.
- "진행 방식 2번"이 '끝까지 연속 진행'이면 단계마다 보고만 하고 멈추지 않고 다음 단계로 이어간다. 단, 확인에 실패한 항목이 있으면 그 단계에서 멈추고 알린다.
- "디자인 확인 3번"이 '한 번 멈춤'이면 2단계에서 디자인 시스템(컬러·서체·대표 화면 1개)을 만든 뒤 멈추고 확인을 받는다. 확인 후 같은 2단계 안에서 나머지 페이지를 진행한다.

## 선택값이 쓰이는 곳
| 번호 | 쓰는 단계 |
|---|---|
| 2 | 모든 단계의 마무리 |
| 3, 4, 5, 6 | 2단계 홍보 사이트 구축 |
| 7, 8, 9 | 3단계 분양 접수 운영 |
| 10, 11 | 4단계 사이트 콘텐츠 운영 |
